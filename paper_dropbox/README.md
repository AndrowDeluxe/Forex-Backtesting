# Paper Dropbox

PDFs, die du manuell findest (SSRN, Trading-Communities, Kursmaterial, etc.)
einfach hier ablegen. `python scripts/research_paper_pipeline.py` verarbeitet
sie beim naechsten Lauf automatisch -- genau wie automatisch per arXiv
gefundene Papers (gleiche Extraktion, gleicher Auto-Backtest-Pfad).

Dieser Ordner ist gitignored -- die PDFs selbst landen nie im Repo/Commit.
